Циклы

Если нужно сделать одно и то же много раз, не копируйте код, а используйте цикл. Цикл for перебирает элементы по очереди. Чаще всего его используют с функцией range(), которая создаёт последовательность чисел. Счёт начинается с нуля, а последнее число не включается. 


for i in range(5):
    print(i)       #0, 1, 2, 3, 4

for letter in "Python":
    print(letter)  #по одной букве

Цикл while работает, пока условие остаётся истинным. Он удобен, когда заранее неизвестно, сколько раз нужно повторять. Если условие никогда не станет ложным, цикл будет бесконечным. Остановить такую программу можно сочетанием клавиш Ctrl + C. 


count = 3
while count > 0:
    print(count)
    count -= 1

Ходом цикла можно управлять: break немедленно завершает цикл, а continue пропускает остаток текущего шага и переходит к следующему. 


for n in range(1, 11):
    if n % 2 == 0:
        continue      #пропускаем чётные
    if n > 7:
        break         #выходим после 7
    print(n)          #1, 3, 5, 7
