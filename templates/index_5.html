Условия

Обычно программа не просто идёт сверху вниз, а выбирает путь в зависимости от обстоятельств. Для этого служит конструкция if. Python проверяет условия по порядку: как только находится первое истинное, выполняется его блок, а остальные пропускаются. 


temperature = 15

if temperature > 25:
    print("Жарко")
elif temperature > 10:
    print("Комфортная погода")
else:
    print("Холодно")

Блоки elif и else необязательны. Блок else срабатывает, если ни одно условие не подошло.

Главная особенность Python - отступы. После двоеточия следующие строки сдвигаются на четыре пробела, и именно этот сдвиг показывает, какой код относится к условию. Неверные отступы приводят к ошибке IndentationError.

Принадлежность значения набору можно проверить с помощью in. Кроме того, пустая строка, число 0, пустой список и None считаются ложными значениями, а всё остальное - истинными. 


answer = input("Продолжить? (да/нет): ")
if answer in ("да", "yes", "y"):
    print("Продолжаем")
