Словари

Словарь хранит данные в виде пар «ключ: значение». Это как телефонная книга, где по имени находится номер. Значение достаётся по ключу, а не по номеру позиции. 


user = {"name": "Анна", "age": 25}

print(user["name"])         #Анна
user["city"] = "Москва"        #добавить новую пару
print(user.get("phone"))     #None, ошибки не будет

Если обратиться к несуществующему ключу через квадратные скобки, возникнет ошибка KeyError. Метод get() вместо ошибки возвращает None или значение, которое вы укажете вторым аргументом.

Чтобы перебрать словарь, используйте метод items():


for key, value in user.items():
    print(key, "->", value)

Как выбрать коллекцию: нужен упорядоченный изменяемый набор - список; неизменяемый - кортеж; доступ по имени - словарь; только уникальные значения - множество.
