Переменные и типы данных

Переменная - это именованная область памяти, предназначенная для хранения данных, которые могут изменяться в процессе выполнения программы. Простыми словами, это ярлык или «коробка», внутри которой лежит определенное значение.

В Python переменные создаются в момент присваивания им значения с помощью знака равенства =.


#создаем переменную, хранящую число
a = 10
#создаем переменную, хранящую строку
b = "HelloWorld!"
#создаем переменную, хранящую дробное число
c = 3.14
#создаем переменную, хранящую значение
d = True
