О проекте

Этот сайт создан как источник информации о базовых и необходимых знаниях для начинающих программистов о языке программирования Python.

Он написан с использованием Python (Flask), JavaScript, HTML и CSS.

Содержимое сайта с каждой страницей поэтапно раскрывает базовую логику Python (переменные, условия, циклы).

Пользователь самостоятельно перемещается по страницам с помощью кнопок Назад/Далее.

На момент написания этого текста на сайте присутствуют {{total}} страниц, количество которых в будущем увеличится.
