Списки

Список хранит упорядоченный набор элементов в квадратных скобках. Его можно изменять после создания. Нумерация элементов начинается с нуля, а отрицательные индексы отсчитываются с конца. 


fruits = ["яблоко", "банан", "вишня"]

print(fruits[0])     #яблоко
print(fruits[-1])    #вишня

fruits.append("груша")      #добавить в конец
fruits.remove("банан")      #удалить по значению
fruits[0] = "апельсин"      #заменить элемент
print(len(fruits))          #количество элементов

Из списка можно взять часть с помощью среза: numbers[1:4] вернёт элементы с индексами 1, 2 и 3. Перебирать список удобно циклом for.

Генератор списка создаёт новый список в одну строку:


squares = [x ** 2 for x in range(1, 6)]
print(squares)    #[1, 4, 9, 16, 25]
