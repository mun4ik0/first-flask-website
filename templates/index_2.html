Установка Python и первая программа

Скачайте Python с официального сайта python.org. Выбирайте последнюю стабильную версию третьей ветки. Во время установки на Windows обязательно поставьте галочку Add Python to PATH: она позволит запускать Python из любого места командной строки.

Чтобы проверить установку, откройте терминал и введите команду, которая покажет номер версии: 


python --version

Создайте файл hello.py и напишите в нём одну строку. Функция print() выводит на экран всё, что вы передали ей в скобках. Текст в кавычках называется строкой. 


#выводим текст на экран
print("Привет, мир!")

Запустите файл командой python hello.py. Всё, что идёт после символа # в строке, Python игнорирует: так оформляются комментарии для людей.
