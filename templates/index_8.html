Кортежи и множества

Кортеж похож на список, но после создания его нельзя изменить. Он записывается в круглых скобках и подходит для данных, которые не должны меняться, например для координат. 


point = (10, 20)
x, y = point            #распаковка
print(x, y)            #10 20

Множество содержит только уникальные элементы и не хранит порядок. Оно удобно для удаления дубликатов и для проверки, входит ли значение в набор. 


numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(unique)           #{1, 2, 3}

a = {1, 2, 3}
b = {3, 4}
print(a | b)            #объединение: {1, 2, 3, 4}
print(a & b)            #пересечение: {3}
