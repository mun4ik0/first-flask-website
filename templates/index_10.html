Функции

Когда один и тот же код нужен в нескольких местах, его оформляют в функцию. Это именованный блок, который можно вызывать сколько угодно раз. Слово def объявляет функцию, в скобках перечисляются параметры, а return возвращает результат наружу. Значения, которые вы передаёте при вызове, называются аргументами. 


def greet(name):
    return f"Привет, {name}!"

message = greet("Анна")
print(message)    #Привет, Анна!

У параметров могут быть значения по умолчанию. Функция может возвращать и несколько значений сразу. 


def power(base, exponent=2):
    return base ** exponent

print(power(5))       #25
print(power(2, 10))   #1024

def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([4, 8, 1, 9])

Хорошая функция делает одну задачу и называется глаголом: calculate_total, send_message. Переменные, созданные внутри функции, существуют только в ней и недоступны снаружи. Это называется областью видимости.
